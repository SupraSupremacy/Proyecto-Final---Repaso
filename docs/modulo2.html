Módulo 3.3

// Módulo 3.3 — Administración de Bases de Datos

Duración

12 semanas

Competencia

Definir procedimientos, esquemas y políticas de seguridad de una base de datos, supervisando además el desempeño de las aplicaciones que obtienen recursos de estas.

Objetivos del módulo

Desarrollar las competencias que permiten realizar una adecuada gestión de una base de datos, asegurando la integridad de la información almacenada en ella.

Herramientas utilizadas

  • Microsoft Access
  • SQL (MySQL / SQL Server)
  • Power BI
  • Microsoft Excel
  • HTML / CSS
  • Windows Batch (backups)

Situación problemática

Las caídas constantes de la base de datos de un sistema informático se deben a que no se administra, gestiona y planifica adecuadamente, generando atrasos en la cadena productiva, malestar en los usuarios internos y externos, erogación de recursos de manera innecesaria y una mala imagen de la entidad.
