Módulo 3.6

// Módulo 3.6 — Desarrollo multiplataforma con .NET MAUI

Duración

12 semanas

Herramientas utilizadas

  • Visual Studio
  • C#
  • .NET 10 (.NET MAUI)
  • XAML
  • Android SDK
  • iOS SDK
  • Android Emulator
  • iOS Simulator

Definiciones y funciones de las herramientas

Visual Studio

IDE para desarrollar, depurar, compilar y desplegar aplicaciones; incluye diseñador visual, IntelliSense y gestión de proyectos.

Lo que aprendimos: Crear soluciones, diseñar formularios, compilar, depurar con breakpoints y administrar referencias.

Ver a fondo

Visual Studio organiza el proyecto en solución, proyecto, formularios y código. Se aprende a validar entradas, separar lógica por eventos y depurar paso a paso para encontrar estados incorrectos. En la práctica, esto ayudó a construir interfaces WinForms con DataGridView y botones, evitando duplicar lógica y detectando valores nulos antes de guardar. También se usó para configurar compilación en Debug/Release y revisar referencias externas.

C#

Lenguaje de programación orientado a objetos del ecosistema .NET.

Lo que aprendimos: Sintaxis, clases, eventos, validaciones, manejo de excepciones y programación orientada a objetos.

Ver a fondo

C# permitió modelar clases y métodos para el aplicativo, encapsular datos y responder a eventos de la interfaz. Se practicó validación, conversión de tipos, recorridos de colecciones y manejo de excepciones. La curva incluyó pasar de scripts simples a un proyecto con múltiples archivos, manteniendo responsabilidades separadas y usando métodos reutilizables para cálculos.

.NET 10 (.NET MAUI)

Framework multiplataforma para crear apps nativas de Android, iOS, macOS y Windows compartiendo código.

Lo que aprendimos: Compartir código y XAML entre plataformas y generar builds Android/iOS/Windows.

Ver a fondo

Se desarrollaron apps multiplataforma compartiendo XAML y C#. Se aprendió a configurar targets Android/iOS/Windows y resolver diferencias de plataforma. La práctica incluyó layouts, controles, navegación y pruebas en emuladores. También se gestionaron recursos y assets.

XAML

Lenguaje de marcado declarativo para definir interfaces, recursos, estilos y data binding.

Lo que aprendimos: Diseñar interfaces, layouts, recursos, estilos y enlaces de datos.

Ver a fondo

Se definió la UI de forma declarativa con layouts, recursos, estilos y enlace de datos. Se aprendió la jerarquía de controles y el ciclo de renderizado. La práctica incluyó layouts Grid/Stack/Flex/Absolute y páginas navegables. También se corrigieron problemas de espacio y alineación.

Android SDK

Conjunto de herramientas/APIs para compilar y ejecutar aplicaciones Android.

Lo que aprendimos: Configurar compilación Android y usar APIs del sistema móvil.

Ver a fondo

Se usaron las APIs y herramientas de Android para compilar y ejecutar la app en emulador o dispositivo. Se comprendió configuración de targets, permisos y recursos Android. La práctica incluyó resolver diferencias de plataforma y depurar en Android.

iOS SDK

Conjunto de herramientas/APIs para compilar y ejecutar aplicaciones iOS.

Lo que aprendimos: Configurar compilación iOS y usar APIs del sistema móvil.

Ver a fondo

Se usaron herramientas y APIs de Apple para compilar y probar en simulador o dispositivo. Se comprendió la configuración de targets iOS y recursos. La práctica incluyó validar comportamiento y layouts en iOS.

Android Emulator

Emulador Android para probar la app sin dispositivo físico durante el desarrollo.

Lo que aprendimos: Probar comportamiento, layouts y eventos en Android sin dispositivo físico.

Ver a fondo

Se probó la app en un dispositivo virtual Android para validar flujo, layouts y eventos. Se aprendió a lanzar emulador, desplegar y leer logs. La práctica incluyó detectar fallos de UI y ciclo de vida.

iOS Simulator

Simulador iOS para probar la app sin dispositivo físico durante el desarrollo.

Lo que aprendimos: Probar comportamiento, layouts y eventos en iOS sin dispositivo físico.

Ver a fondo

Se probó la app en un simulador iOS para validar flujo, layouts y eventos. Se aprendió a lanzar simulador, desplegar y depurar. La práctica incluyó verificar compatibilidad visual.
