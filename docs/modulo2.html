Módulo 3.3

// Módulo 3.3 — Administración de Bases de Datos

Duración

12 semanas

Competencia

Definir procedimientos, esquemas y políticas de seguridad de una base de datos, supervisando además el desempeño de las aplicaciones que obtienen recursos de estas.

Objetivos del módulo

Desarrollar las competencias que permiten realizar una adecuada gestión de una base de datos, asegurando la integridad de la información almacenada en ella.

Herramientas utilizadas

  • Microsoft Access
  • SQL (MySQL / SQL Server)
  • Power BI
  • Microsoft Excel
  • HTML / CSS
  • Windows Batch (backups)

Definiciones y funciones de las herramientas

Microsoft Access

Sistema gestor de bases de datos de escritorio para crear tablas, consultas, formularios e informes.

Lo que aprendimos: Diseñar tablas, relaciones, consultas, formularios e informes de base de datos.

Ver a fondo

Access se usó para crear tablas, relaciones y consultas en bases desktop. Se aprendió a modelar entidades, definir claves y relaciones, y a construir formularios e informes para usuarios finales. La curva incluyó migrar o comparar base antes/después del diseño.

SQL (MySQL / SQL Server)

Lenguaje para definir, consultar y administrar bases de datos relacionales (DDL/DML).

Lo que aprendimos: Crear bases y tablas, CRUD, filtros, JOIN, funciones, procedimientos, triggers y transacciones.

Ver a fondo

Los scripts cubrieron DDL, DML, filtros, joins, funciones, procedimientos, triggers y transacciones. Se aprendió a crear base desde cero, cargar datos, consultar con operadores requeridos y mantener integridad con ALTER/UPDATE/DELETE. La práctica también incluyó backups, restores y consultas orientadas a dashboard.

Power BI

Herramienta de inteligencia de negocios para modelar datos y crear dashboards e informes interactivos.

Lo que aprendimos: Limpiar y modelar datos, crear medidas DAX, relaciones y dashboards interactivos.

Ver a fondo

Power BI se usó para importar datos, transformar columnas, crear relaciones y medidas DAX, y visualizar KPIs en dashboards. Se aprendió a distinguir modelo de informe, usar slicers/filtros y validar cifras contra las consultas SQL. La curva incluyó comparar datos limpios con datos crudos.

Microsoft Excel

Hoja de cálculo para análisis, fórmulas, tablas dinámicas, gráficos e intercambio de datos.

Lo que aprendimos: Fórmulas, tablas dinámicas, gráficos, importación/exportación y análisis exploratorio.

Ver a fondo

Excel se usó para exportar/importar tablas, preparar CSV, fórmulas y tablas dinámicas. Se aprendió a limpiar datos antes de análisis y a documentar resultados en hojas por caso de negocio. La práctica incluyó cruces y resúmenes rápidos.

HTML / CSS

Lenguajes de marcado y estilo para estructurar y presentar contenido en páginas web.

Lo que aprendimos: Estructurar contenido semántico, estilos, layouts responsive y componentes visuales.

Ver a fondo

Se usaron HTML semántico y CSS para estructurar páginas, estilos, navegación, cards y layouts responsive. En la práctica se aplicaron grids, sticky header, animaciones CSS y componentes reutilizables para páginas de trabajo e informes.

Windows Batch (backups)

Script de comandos para automatizar tareas del sistema operativo, como respaldos y copias.

Lo que aprendimos: Automatizar respaldos con comandos, copias, scripts y tareas programadas.

Ver a fondo

Se crearon scripts .bat para automatizar copias/backups y ejecutar comandos SQL. Se aprendió a registrar pasos, validar rutas y probar restauración. La práctica incluyó backups full/diff/log y comparación de resultados.

Situación problemática

Las caídas constantes de la base de datos de un sistema informático se deben a que no se administra, gestiona y planifica adecuadamente, generando atrasos en la cadena productiva, malestar en los usuarios internos y externos, erogación de recursos de manera innecesaria y una mala imagen de la entidad.
