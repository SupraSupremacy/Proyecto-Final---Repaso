Módulo 3.8

// Módulo 3.8 — Proyecto innovador de desarrollo de software

Duración

3 Semanas

Competencia

Desarrollar aplicaciones de software orientadas a la información general para la toma de decisiones acertadas y confiables en una empresa o entidad.

Objetivos del módulo

Desarrollar las competencias que permitan la creación de aplicaciones de software orientadas a la producción de información gerencial para la toma de decisiones acertadas y confiables dentro de una empresa o entidad.

Herramientas utilizadas

  • Node.js / npm
  • TypeScript
  • Vite
  • Vitest
  • ESLint
  • Python
  • Flask
  • Jinja2
  • Git & GitHub Pages
  • HTML / CSS

Definiciones y funciones de las herramientas

Node.js / npm

Entorno de ejecución de JavaScript y gestor de paquetes para dependencias y scripts de build.

Lo que aprendimos: Gestionar dependencias, scripts, entorno de desarrollo y build del proyecto frontend.

Ver a fondo

Se instaló dependencias, ejecutó scripts dev/build/test y entendió package.json. Se aprendió a diferenciar dependencias de desarrollo, versiones y lock. La práctica incluyó ejecutar Vite y Vitest desde terminal.

TypeScript

Superset tipado de JavaScript que se compila a JavaScript para mejorar mantenibilidad y detección de errores.

Lo que aprendimos: Tipar variables/funciones, interfaces, módulos y compilar a JavaScript.

Ver a fondo

Se practicó tipado de funciones, interfaces, módulos y DOM. Se aprendió a detectar errores en compile-time y a estructurar código en archivos separados. La práctica incluyó estado de juego tipado y funciones puras.

Vite

Servidor de desarrollo rápido y empaquetador moderno para aplicaciones web frontend.

Lo que aprendimos: Desarrollo con HMR, bundling y build optimizado para producción.

Ver a fondo

Vite se usó como servidor de desarrollo con HMR y empaquetador final. Se aprendió a configurar scripts, entry points y assets, y a optimizar build para publicación. La práctica incluyó debugging de rutas y carga de módulos.

Vitest

Corredor de pruebas unitarias integrado con Vite para validar componentes y lógica.

Lo que aprendimos: Escribir y ejecutar pruebas unitarias, casos de borde y resultados esperados.

Ver a fondo

Se escribieron pruebas unitarias para lógica de juego y se interpretaron resultados. Se aprendió a definir casos mínimos, verificar cálculos y reproducir errores antes de corregir. La práctica ayudó a mejorar robustez.

ESLint

Analizador estático de código para detectar errores y aplicar reglas de calidad/estilo.

Lo que aprendimos: Aplicar reglas de calidad, corregir estilo y detectar errores antes de ejecutar.

Ver a fondo

Se configuraron reglas y se corrigieron advertencias/errores de estilo. Se aprendió a mantener código consistente y detectar patrones problemáticos temprano. La práctica incluyó ajustar reglas TypeScript.

Python

Lenguaje de propósito general usado para scripting, backends, automatización y procesamiento de datos.

Lo que aprendimos: Scripting, automatización, estructuras de datos y backend web.

Ver a fondo

Se usó Python para backend, scripts y automatización de generación estática. Se aprendió a manejar estructuras de datos, rutas, rendering y construcción reproducible. La práctica incluyó generación de docs y JSON.

Flask

Microframework web para Python para crear aplicaciones y APIs HTTP.

Lo que aprendimos: Crear rutas, renderizar plantillas, exponer endpoints y servir una app web.

Ver a fondo

Se crearon rutas dinámicas, renderizado de plantillas y endpoints JSON. Se aprendió a separar datos, vistas y archivos estáticos. La práctica incluyó despliegue estático a GitHub Pages.

Jinja2

Motor de plantillas para generar HTML dinámico usando variables, filtros y estructuras de control.

Lo que aprendimos: Herencia de plantillas, bloques, filtros, variables y generación dinámica de HTML.

Ver a fondo

Se extendieron templates con herencia, bloques, loops, condicionales y filtros. Se aprendió a compartir componentes como navbar y a generar rutas relativas/absolutas según entorno.

Git & GitHub Pages

Control de versiones y plataforma para publicar sitios estáticos desde un repositorio.

Lo que aprendimos: Control de versiones, commits, push, branches y despliegue estático.

Ver a fondo

Se inicializó repositorio, se hicieron commits y push, se gestionó visibilidad y se publicó sitio estático. Se aprendió flujo básico y troubleshooting de builds de Pages.

HTML / CSS

Lenguajes de marcado y estilo para estructurar y presentar contenido en páginas web.

Lo que aprendimos: Estructurar contenido semántico, estilos, layouts responsive y componentes visuales.

Ver a fondo

Se usaron HTML semántico y CSS para estructurar páginas, estilos, navegación, cards y layouts responsive. En la práctica se aplicaron grids, sticky header, animaciones CSS y componentes reutilizables para páginas de trabajo e informes.

Situación problemática

Ciertas empresas toman decisiones erróneas basadas en información no confiable debido a la carencia de sistemas de información general, lo cual provoca altas pérdidas financieras y disminución en oportunidades de negocio tanto a nivel nacional como internacional.
